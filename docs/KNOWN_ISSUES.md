# Known issues

Render Free can take about a minute to wake after 15 minutes without inbound traffic. Render serves the loading page until the process can respond. Chaser displays its own loading state while the dashboard loads. [Render Free startup behavior](https://render.com/docs/free#spinning-down-on-idle)

For a timed demo, open the hosted dashboard a minute early, use the local mock walkthrough if the network is slow, or use an always-on Render instance if paid compute is available.
